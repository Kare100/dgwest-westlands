# DG West Westlands: an independent guide

A static website about **DG West**, a 25-floor residential and hotel-apartment tower by Reportage Group on Sports Road, Westlands, Nairobi.

- **Residences:** studio (41 m²), one bedroom (70 m²) and two bedroom (90 m²), with every room size printed in the developer's brochure
- **Floor plans:** interactive SVG plans of the typical floor (10 homes, floors 5–24) and each home type, redrawn from the brochure's dimensions
- **Amenities:** the 25th-floor infinity pool, gym and spas, the roof garden, and the floor 3–4 facilities
- **Location:** a map of Sports Road and the developer's drive times

## Photos
All photos are real photographs from [Unsplash](https://unsplash.com/license), used under the Unsplash License. The building is still under construction, so none of them show DG West. They show Nairobi and comparable interiors.

## Run and deploy
It's plain HTML, CSS and JS with no build step. Open `index.html` locally, or import the repository into Vercel (Framework preset: **Other**) and it deploys as-is.
